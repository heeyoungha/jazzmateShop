2_summary_dag.pyGPT Batch 완료 대기, 요약 결과 저장, Embedding Batch 제출Sensor는 mode=reschedule로 worker 슬롯 점유를 줄임
3_embedding_vector_dag.pyEmbedding Batch 완료 대기, 벡터 저장, 완료 알림embedding_vectors를 추천 서비스의 검색 입력으로 제공
pipeline_servicesDAG에서 호출하는 서비스 레이어DAG 파일은 오케스트레이션만 담당하고 DB/API 로직은 서비스로 분리
SupabaseService파이프라인 상태와 결과 저장소 접근큰 payload는 XCom 대신 PostgreSQL에 저장
OpenAIServiceGPT/Embedding Batch 제출과 상태 조회Batch ID 선기록으로 재실행 시 중복 제출을 방지
error_history크롤링/Batch 처리 실패 이력 저장RetryableError는 Airflow retry, PermanentError는 item 단위 기록
