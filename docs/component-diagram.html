플로우 02 — AI 추천 처리 + Polling

FastAPI가 임베딩 생성 → 취향 벡터 블렌딩 → pgvector 유사도 검색 → 재순위 → 추천 사유 생성 → Spring 콜백하는 플로우. 프론트는 polling으로 상태를 확인한다.

  }

  package "2. 임베딩 + 취향 벡터" {
