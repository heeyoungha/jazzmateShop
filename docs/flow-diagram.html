플로우 01 — 감상문 작성 + AI 추천 요청

사용자가 감상문을 작성하면 Spring Boot가 DB에 저장하고, 커밋 후 비동기로 FastAPI에 추천을 요청한다.

전체 시퀀스
@startuml
skinparam backgroundColor #FAFAFA
skinparam sequenceArrowThickness 1.5
skinparam participantFontSize 13

actor 사용자
participant "Frontend\n(React)" as FE
participant "Spring Boot" as SP
participant "PostgreSQL" as DB
participant "FastAPI" as FA

사용자 -> FE : 감상문 작성 후 제출
FE -> SP : POST /api/user-reviews\n{albumName, reviewContent, userId, ...}
SP -> DB : INSERT user_reviews\n(recommendationStatus = PENDING)
DB --> SP : saved (id)
SP --> FE : 201 { data: { id } }
FE -> FE : navigate(/recommend/{id})

SP -> SP : RecommendationRequestEvent 발행\n(AFTER_COMMIT, @Async)
SP ->> FA : POST /recommend/review\n{review_id, review_content, user_id}
note right of FA
  202 Accepted
  BackgroundTask 등록
  → 플로우 02로 이어짐
end note
@enduml

Swagger API

POST /api/user-reviews
새 창
모듈역할핵심 계약
Frontend감상문 폼 렌더링, POST 요청, data.id로 페이지 이동응답 data.id 로 /recommend/{id} 이동
Spring Boot감상문 저장, 커밋 후 FastAPI 비동기 호출AI 요청 실패가 감상문 저장 트랜잭션에 영향 없음
FastAPI추천 요청 수신 후 백그라운드 처리 시작202 즉시 반환, 처리 결과는 콜백으로 전달
DBuser_reviews 저장, recommendationStatus = PENDING 초기값—

플로우 02 — AI 추천 처리 + Polling + 재시도

FastAPI가 추천을 처리하고 Spring Boot에 콜백을 전송한다. 프론트는 polling으로 상태를 확인한다.

성공 경로 (COMPLETED)
@startuml
skinparam backgroundColor #FAFAFA
skinparam sequenceArrowThickness 1.5
skinparam participantFontSize 13

participant "Frontend\n(React)" as FE
participant "Spring Boot" as SP
participant "FastAPI" as FA
participant "PostgreSQL" as DB
participant "OpenAI API" as OAI

note over FE,FA : 플로우 01에서 이어짐 (/recommend/{id} 진입 직후)

FE -> SP : GET /api/user-reviews/{id}
SP --> FE : recommendationStatus=PENDING

== FastAPI 추천 처리 (백그라운드) ==
FA -> OAI : Embeddings API\n(감상문 임베딩 생성)
OAI --> FA : review_embedding
FA -> DB : SELECT user_reviews.review_embedding\n(과거 감상문 임베딩)
FA -> DB : SELECT album_reference.embedding\n(감상 앨범 임베딩)
FA -> FA : TasteVectorService\n(감상문 60% + 개인화 40% 블렌딩)
FA -> DB : match_albums() pgvector 유사도 검색
FA -> DB : SELECT mb_album 메타 (재순위용)
FA -> FA : RecommendationRerankService\n(벡터 80% + 메타 20%)
FA -> OAI : Chat API (추천 사유 생성 ×3)
OAI --> FA : reasons[]
FA -> SP : POST /api/user-reviews/{id}/recommendations\n{status: COMPLETED, recommendations[], embedding}
SP -> DB : INSERT recommend_album\nUPDATE recommendationStatus → COMPLETED

== polling ==
loop polling (3초 간격)
  FE -> SP : GET /api/user-reviews/{id}
  SP --> FE : recommendationStatus=COMPLETED\n+ recommendations[]
end
FE -> FE : 추천 카드 렌더링
@enduml

플로우 03 — 내 감상문 목록 조회

공개된 감상문을 최신순으로 페이지네이션 조회한다. 무한 스크롤로 추가 로드한다.

전체 시퀀스
@startuml
skinparam backgroundColor #FAFAFA
skinparam sequenceArrowThickness 1.5
skinparam participantFontSize 13

actor 사용자
participant "Frontend\n(React)" as FE
participant "Spring Boot" as SP
participant "PostgreSQL" as DB

사용자 -> FE : /my-reviews 진입
FE -> SP : GET /api/user-reviews?page=0&size=10
SP -> DB : SELECT user_reviews\nWHERE isPublic=true\nORDER BY createdAt DESC\nLIMIT 10
DB --> SP : Page<UserReviewSummary>
SP --> FE : { content[], last, number }
FE -> FE : 감상문 카드 렌더링

loop 무한 스크롤 (last=false인 동안)
  사용자 -> FE : 스크롤 하단 도달
  FE -> SP : GET /api/user-reviews?page={number+1}&size=10
  SP -> DB : SELECT (다음 페이지)
  DB --> SP : Page<UserReviewSummary>
  SP --> FE : { content[], last, number }
  FE -> FE : 카드 추가 렌더링
end
@enduml

Swagger API

GET /api/user-reviews
새 창
모듈역할핵심 계약
Frontend목록 렌더링, 무한 스크롤, 페이지 증가 요청last=true면 추가 요청 중단
Spring Boot공개 감상문 페이지네이션 조회isPublic=true만 반환, createdAt DESC
DBuser_reviews SELECT—

플로우 04 — 전문가 리뷰 목록/상세 조회

GPT 요약이 완료된 전문가 리뷰를 무한 스크롤로 조회하고, 카드 클릭 시 상세 페이지로 이동한다.

목록 조회
@startuml
skinparam backgroundColor #FAFAFA
skinparam sequenceArrowThickness 1.5
skinparam participantFontSize 13

actor 사용자
participant "Frontend\n(React)" as FE
participant "Spring Boot" as SP
participant "v_review_summary\n(뷰)" as DB

사용자 -> FE : /critics 진입
FE -> SP : GET /api/critics?page=0&size=10
SP -> DB : SELECT\nWHERE reviewSummary IS NOT NULL\nORDER BY createdAt DESC
DB --> SP : Page<CriticsReviewSummary>
SP --> FE : { content[], last, number }
FE -> FE : 리뷰 카드 렌더링

loop 무한 스크롤 (last=false인 동안)
  사용자 -> FE : 스크롤 하단 도달
  FE -> SP : GET /api/critics?page={number+1}&size=10
  SP --> FE : { content[], last, number }
  FE -> FE : 카드 추가 렌더링
end
@enduml
상세 조회
@startuml
